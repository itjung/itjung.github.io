# Homepage Update for itjung.github.io

This folder contains direct-upload static files for a refreshed GitHub Pages homepage.

## Files

- `index.html` — New homepage for Intae Jung and the Early Universe Group
- `research.html` — Research overview
- `people.html` — Lab/group page
- `publications.html` — Selected publications
- `contact.html` — Contact page
- `styles.css` — Shared visual styling
- `M31_low_res.jpg` — Local background image
- `research_files/` — Reused figure slides from the previous research page

## Before uploading

The files now use the CBNU affiliation, department, email address, mailing address, group description, and publication summary from `IJung_CV_with_Publications.docx`.

Optional personalizations before uploading:

- Add a group logo or member photos.
- Replace `M31_low_res.jpg` if you want to use a different local background image.
- Update the CV PDF link or upload a current PDF named `IntaeJung_Curriculum_Vitae_updated.pdf`.

If your GitHub Pages repository already has `IntaeJung_Curriculum_Vitae_updated.pdf`, the CV link will keep working. Otherwise, upload the updated PDF with that filename or change the link in the navigation.

## Upload

Copy these files into the root of your `itjung.github.io` repository and commit/push them.
